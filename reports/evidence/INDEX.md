# Responsive Layout & UX Evidence Index

This directory stores responsive layout evidence generated during E2E verification.
Large PNG binaries are excluded from version control via `.gitignore` to prevent repository bloat.

## Evidence Artifacts

1. **`responsive-summary.json`**
   - JSON report recording viewport dimensions, scroll widths, client widths, and horizontal overflow status (all 0px overflow).
   - Viewports verified:
     - Mobile: 360 x 740 px (`mobile-360.png`)
     - Tablet: 768 x 1024 px (`tablet-768.png`)
     - Desktop: 1280 x 800 px (`desktop-1280.png`)

2. **Local PNG Screenshots (Untracked)**
   - `mobile-360.png` (~29 KB)
   - `tablet-768.png` (~516 KB)
   - `desktop-1280.png` (~576 KB)

Generated by: `node scripts/capture-responsive-evidence.cjs`
Suite: `npm run test:ux:e2e`
